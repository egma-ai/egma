# Built-in background sound assets

These immutable files are 20-second, 24 kHz, mono, signed 16-bit PCM WAV loops prepared from the CC0 high-quality MP3 previews recorded in `manifest.json`. Each source was normalized to -23 LUFS with a -3 dB true-peak ceiling. A 250 ms fade at both boundaries prevents a click when the file loops. The Home with TV effect is constructed from performed crowd dialogue and television hiss; it does not use the candidate with unidentified news footage.

The source pages and licenses were verified on 2026-09-10. Automated inspection verified each prepared format, duration, checksum, and non-clipping level. A human listening review is still required before release.
