## Install the skills

Run this command in your voice agent repository:

```bash
npx skills add egma/egma
```

Egma includes two skills:

1. `integrate-egma` registers your voice agent, connects it to Egma and starts test runs.
2. `write-egma-tests` writes voice agent tests as Markdown files from your agent's prompts, tools and code.

## Install the CLI

```bash
npm install --global egma-cli
```

## Sign in

```bash
egma login
```

The command opens your browser so you can sign in and select an Egma project.

## Configure personas from the CLI

Persona commands are promptless and use the project in `egma/config.yaml`.

```bash
egma persona list
egma persona settings <Persona ID>
egma persona capabilities --stt-provider <id> --stt-model <id> \
  --tts-provider <id> --tts-model <id>
```

Use the capability response to select supported values. The `use`, `create`,
and `update` commands accept complete model and speech controls. Run
`egma persona <command> --help` for the exact flags. Use a full simulation to
check audible behavior and interruptions.
