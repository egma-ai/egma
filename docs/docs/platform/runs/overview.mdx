---
title: "What is a run?"
---

A **run** executes one complete test suite against one agent connection.
Each test and selected persona combination in a run produces one [simulation](/docs/platform/runs/simulation).
A suite with two tests that each select two personas produces four
simulations in a run.


[Start a run](/docs/platform/runs/start-and-follow-a-run), then [review its results](/docs/platform/runs/review-a-run) to inspect progress, transcripts, recordings, and individual grades.
