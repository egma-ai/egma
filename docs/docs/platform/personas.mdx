---
title: "What is a persona?"
---

A persona defines the caller's identity, personality, language, and speech
settings. The test describes the situation. Reuse a persona across tests when
you want the same kind of caller in different situations.


## Persona and scenario

The persona describes who the caller is. The scenario describes what they want in one conversation. For example, “Caller in a hurry” can ask to book, reschedule, or cancel an appointment in different tests.

## Personas in a run

Each test selects one or more personas. A test with two personas creates two simulations per run. A run saves the selected behavior versions and project model settings, so later edits apply to future runs.

## Add or update a persona

- [Add a persona](/docs/platform/personas/add-a-persona) to use an existing caller or create your own.
- [Update a persona](/docs/platform/personas/update-a-persona) to change behavior, models, or voice settings.
