You need a Retell agent, a Retell API key that can access it, and an Egma project. For CLI setup, complete [CLI sign-in](/skills-cli-sdks/cli/install#sign-in-and-initialize) first.

Start with a text connection to check conversation behavior, or a web-call
connection to test voice. Both connect directly to your Retell agent.
