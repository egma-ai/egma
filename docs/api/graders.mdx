title: "Project graders"

A project grader connects one project to one shared grader definition. It owns
that project's scope, settings, and individual pass threshold. It does not copy
Egma's prompt, code, or model choice.

Egma automatically adds one **Expected behaviors** project grader to every
project. Its fixed scope selects all simulations and no production traces, and
it cannot be removed. Its pass threshold starts at `1` and is editable. Every
other project grader starts from the [grader library](/api/grader-library).

## List graders

**`GET /v1/graders`**

<ParamField query="projectId" type="string">
  The `prj_` project identifier. Omit it when your API key is already scoped to
  a project.
</ParamField>

<ParamField query="pageToken" type="string">
  The `nextPageToken` from the previous page.
</ParamField>

<ResponseField name="graders" type="array">
  The project's active grader records, ordered by name.
</ResponseField>

<ResponseField name="nextPageToken" type="string | null">
  The next page cursor, or `null` after the last page.
</ResponseField>

```bash
curl "https://your-egma-instance/v1/graders?projectId=prj_abc123" \
  -H "Authorization: Bearer egma_sk_..."
```

## Update a grader

**`PATCH /v1/graders/:graderId`**

Send at least one of the three policy fields. A field you omit does not change.

<ParamField path="graderId" type="string" required>
  The `grd_` project-grader identifier.
</ParamField>

<ParamField query="projectId" type="string">
  The project identifier. Omit it when your API key is project-scoped.
</ParamField>

<ParamField body="scope" type="object">
  The complete scope object. Egma refuses a scope change on a grader whose
  `scopeEditable` is `false`, such as Expected behaviors.
</ParamField>

<ParamField body="settings" type="object">
  One value for each of the definition's settings. For Response latency, send
  `maximum_response_time_ms` as a positive whole number.
</ParamField>

<ParamField body="passThreshold" type="number">
  A normalized value from `0` through `1`. A grade passes this individual
  grader when `score >= passThreshold`.
</ParamField>

```bash
curl -X PATCH \
  "https://your-egma-instance/v1/graders/grd_abc123?projectId=prj_abc123" \
  -H "Authorization: Bearer egma_sk_..." \
  -H "Content-Type: application/json" \
  -d '{ "passThreshold": 0.8 }'
```

The update affects future grading work. Existing grades keep the scope,
settings, and threshold that were frozen when their work was selected.

## Remove a grader

**`DELETE /v1/graders/:graderId`**

Removes an optional project grader and returns status `204`. Grades it already
wrote stay readable on their traces. Egma refuses to remove Expected behaviors.

<ParamField path="graderId" type="string" required>
  The `grd_` project-grader identifier.
</ParamField>

<ParamField query="projectId" type="string">
  The project identifier. Omit it when your API key is project-scoped.
</ParamField>

```bash
curl -X DELETE \
  "https://your-egma-instance/v1/graders/grd_abc123?projectId=prj_abc123" \
  -H "Authorization: Bearer egma_sk_..."
```

## The grader object

<ResponseField name="id" type="string">
  The stable `grd_` identifier for this project's policy.
</ResponseField>

<ResponseField name="projectId" type="string">
  The project that owns this policy.
</ResponseField>

<ResponseField name="graderDefinitionId" type="string">
  The shared `grl_` grader-definition identifier.
</ResponseField>

<ResponseField name="name" type="string">
  The grader name.
</ResponseField>

<ResponseField name="description" type="string | null">
  What quality rule the grader applies and why.
</ResponseField>

<ResponseField name="owner" type="string">
  `egma` for a predefined definition or `organization` for a custom definition.
</ResponseField>

<ResponseField name="type" type="string">
  `llm_as_judge` or `code`.
</ResponseField>

<ResponseField name="modalities" type="array">
  The conversation forms the grader supports: `chat`, `voice`, or both.
</ResponseField>

<ResponseField name="scopeEditable" type="boolean">
  Whether this project may change the scope.
</ResponseField>

<ResponseField name="removable" type="boolean">
  Whether this project may remove the grader. `false` for Expected behaviors.
</ResponseField>

<ResponseField name="scope" type="object">
  The complete project scope. `simulations` contains `all`, `test_suite`, or
  `test` selectors. `production` is `null` or contains `samplePercent` from `1`
  through `100`.
</ResponseField>

<ResponseField name="settings" type="object">
  The values this project supplies for the definition's settings.
</ResponseField>

<ResponseField name="passThreshold" type="number">
  The editable threshold for this grader's own passed or failed result.
</ResponseField>

<ResponseField name="createdAt" type="string">
  ISO 8601 creation time.
</ResponseField>

<ResponseField name="updatedAt" type="string">
  ISO 8601 last-update time.
</ResponseField>
