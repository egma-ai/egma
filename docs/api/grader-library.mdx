The grader library contains reusable grader definitions. A definition owns its
name, execution type, immutable versions, and whether project scope can be
edited. A project grader holds one project's scope and pass threshold.

Egma maintains one shared copy of each predefined definition. When Egma improves
one, it creates a new definition version. Future grading work uses the new
version; work that was already selected keeps its old version.

The first product catalog contains only **Expected behaviors**. Every project
receives its project grader automatically. Its fixed scope selects all
simulations and no production traces, while its pass threshold stays editable.
The API does not yet expose optional Add, Remove, or custom-authoring
operations.

## List definitions

**`GET /v1/grader-library`**

<ParamField query="projectId" type="string">
  Optional project context. Use it to include definitions visible to that
  project.
</ParamField>

<ParamField query="pageToken" type="string">
  The `nextPageToken` from the previous page.
</ParamField>

<ResponseField name="graderLibraryEntries" type="array">
  The visible stable grader definitions.
</ResponseField>

<ResponseField name="nextPageToken" type="string | null">
  The next page cursor, or `null` after the last page.
</ResponseField>

```bash
curl https://your-egma-instance/v1/grader-library \
  -H "Authorization: Bearer egma_sk_..."
```

## The definition object

<ResponseField name="id" type="string">
  The stable `grl_` definition identifier.
</ResponseField>

<ResponseField name="name" type="string">
  The grader's name.
</ResponseField>

<ResponseField name="description" type="string | null">
  What quality rule this grader applies and why.
</ResponseField>

<ResponseField name="type" type="string">
  The grader definition's execution mechanism.
</ResponseField>

<ResponseField name="owner" type="string">
  `egma` for a predefined definition or `customer` for a customer definition.
</ResponseField>

<ResponseField name="projectId" type="string | null">
  The owning project for a customer definition, or `null` for an Egma-owned
  predefined definition.
</ResponseField>

<ResponseField name="scopeEditable" type="boolean">
  Whether a customer may change the scope on its project grader.
</ResponseField>

<ResponseField name="currentDefinitionVersion" type="number">
  The positive integer version that new grading work will freeze.
</ResponseField>

<ResponseField name="createdAt" type="string">
  ISO 8601 creation time.
</ResponseField>

<ResponseField name="updatedAt" type="string">
  ISO 8601 last-update time.
</ResponseField>
