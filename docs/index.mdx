Egma is the open-source platform for teams that need evidence they can trust
before and after a voice agent reaches production. It runs real conversation
simulations from repository-owned tests, receives production conversations
through platform-specific monitoring, and grades completed traces against the
behaviors you expect.

## Get started

<Steps>
  <Step title="Install the public skills">
    Run the bare CLI from the voice-agent repository. It prints the skill
    install command and the exact handoff for the coding agent you already use.

    ```bash
    npx --yes @egma/cli
    ```
  </Step>
  <Step title="Approve sign-in">
    Your coding agent runs `egma login`. Egma opens a device-approval page, and
    you approve the request in the browser.

    ```bash
    egma login
    ```
  </Step>
  <Step title="Connect and author">
    The `integrate-egma` skill keeps discovery read-only, shows the exact setup
    for approval, and uses named commands to connect Retell or LiveKit. It lists
    valid personas, creates one suite, and writes three or four grounded tests.

    ```bash
    egma personas
    egma suite create <directory> --name <name>
    egma validate
    ```
  </Step>
  <Step title="Publish and run">
    After separate publish and run approvals, your coding agent pushes the
    complete repository and follows one suite. Phone runs include a cost warning
    before approval.

    ```bash
    egma push
    egma run <suite-directory>
    ```
  </Step>
</Steps>

Monitoring is a separate requested outcome. A monitoring-only integration skips
connections, suites, tests, and runs. A both integration finishes the reviewed
run and confirms `egma monitoring status`.
