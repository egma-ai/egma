Egma is the open-source platform for teams that need evidence they can trust
before and after a voice agent reaches production. It runs real conversation
simulations from repository-owned tests, receives production conversations
through platform-specific monitoring, and grades completed traces against the
behaviors you expect.

## Get started

<Steps>
  <Step title="Install the CLI">
    Install the npm package once. It provides the `egma` command. The current
    integration skill is still being authored, so this guide gives the coding
    agent the command workflow directly.

    ```bash
    npm install --global egma-cli
    npx --yes skills add egma-ai/egma \
      --skill write-egma-tests
    ```
  </Step>
  <Step title="Approve sign-in and initialize">
    Your coding agent runs `egma login`. Egma opens a device-approval page, and
    you approve the request in the browser. It then binds this repository to an
    existing Project and pulls the current state.

    ```bash
    egma login
    egma init
    ```
  </Step>
  <Step title="Connect and author">
    The coding agent keeps discovery read-only, resolves the exact setup from
    repository facts, and uses named commands to connect Retell or LiveKit. It
    lists valid personas, creates one suite, and writes the smallest grounded
    Test set.

    ```bash
    egma persona list
    egma suite create <directory> --name <name>
    egma push
    ```
  </Step>
  <Step title="Publish and run">
    For supported testing, your end-to-end prompt already asks the coding agent
    to create one Run. The command pushes first, then returns a web results URL.
    Before a real phone Run, the coding agent must warn you that the calls can
    cost money and obtain your approval. The CLI itself does not prompt for
    approval.

    ```bash
    egma run create <suite-directory> \
      --agent <Egma Agent ID> \
      --connection <Connection ID>
    ```
  </Step>
</Steps>

Monitoring is a separate requested outcome. A monitoring-only integration skips
Connections, Suites, Tests, and Runs. The coding agent uses
`egma agent monitoring setup` with an explicit Agent ID and platform.
