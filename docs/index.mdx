Egma is the open-source platform purpose-built for teams shipping voice agents. It lets you simulate real conversations before they reach production, monitor real conversations through platform-specific setup, and automatically grade each exchange against the behaviors you expect.

## Get up and running

<Steps>
  <Step title="Install the CLI">
    Run the Egma wizard from your voice agent's repository. No global install required — `npx` handles it.

    ```bash
    npx @egma/cli
    ```
  </Step>
  <Step title="Connect your agent">
    Egma signs this machine in with a short browser approval, then asks for your Retell or LiveKit credentials to register your agent. Egma uses the credential for discovery and seals it on the platform only when the selected connection needs it. It is never written to a repository file.

    ```bash
    egma connect
    ```
  </Step>
  <Step title="Write tests">
    Create a suite first. The wizard then drives your existing coding agent to
    write its tests under `egma/tests/<suite-directory>/`.

    ```bash
    egma init
    ```
  </Step>
  <Step title="Run tests">
    Push your tests to Egma and start a run. The simulator conducts real conversations with your agent; the grader writes one verdict per expected behavior as each call finishes.

    ```bash
    egma run <suite-directory>
    ```
  </Step>
</Steps>
